What we’re chewing on

Train them, track them, handle them: now, next, and later.

Now · Early build

Rally

Our bench for AI agents: a sandbox and eval harness that checks whether an agent does what you meant, before you ship it. Like a rally course for dogs, it's judged sign by sign. You lay out the course, the agent runs it, and a clean run earns a Q. Agents work their way up from Novice to Master. Built on Claude.

Next

Scout

A scout ranges ahead and reports back. Scout picks up the trail every agent leaves: OpenTelemetry traces plus messages from Claude and Codex sessions, cloud agents, Slack threads, and GitHub issues and pull requests. It brings back one record of what each agent did, asked and decided, and where it's stuck.

Later

Handler

Run enough agents and they all end up waiting on you. Handler reads what Scout brings back and turns every open question into a clear choice with a recommendation. You answer in a word, and Handler passes it back to the agent.

The reporting

Field reports and teardowns on where AI does what people meant, and where it chews the couch instead. First-hand, specific, and backed by numbers we can stand behind, from Aaron Wroblewski and guest practitioners. Subscribe to get the first one.

The Off Leash Lab

Running daily

Agents that train themselves. Every night they review their own work, and the lessons become skills the whole pack picks up. Each decision we close becomes a Rally case, so the next run goes cleaner.
